# K Mani Shankar — Personal Portfolio

A responsive developer portfolio built with HTML, CSS and JavaScript.

## Included
- Responsive portfolio UI
- Personal profile photo
- Dark/light theme switcher
- Recruiter snapshot section
- Skills, experience, projects and education
- Copy-email interaction
- LinkedIn and email links
- Scroll reveal animations

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Customize
- Replace `assets/profile.jpg` with another professional photo if desired.
- Add GitHub/project URLs when ready.
- Add `resume.pdf` and a Resume button when your final resume is ready.

## Deploy
Upload the folder to GitHub Pages, Netlify, Vercel, or another static hosting provider.
